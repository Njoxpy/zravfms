# ZRA API Documentation

Welcome to the Zanzibar Revenue Authority (ZRA) Virtual Fiscal Management System (VFMS) Hotel API documentation site.

> This guide is not an official ZRA publication. It is an independent explanation created to help people understand VFMS hotel integration.

This project contains the VFMS hotel API reference, integration guide, and developer notes in a Next.js documentation site.

- Use **Introduction** for authentication, workflow, and required request headers.
- Use **API Endpoints** for endpoint details and JSON request examples.
- Use **Response Codes** for API status meanings and checkout report requirements.

> For project setup and local development, see `README.md`.
